# Drivwon CMS guide (Sanity)

Open the Studio at https://drivwon.sanity.studio and sign in.

## Change any text, image or video

1. Open **Pages** (or Services, Locations, Case studies).
2. Click the page, then the section you want to change.
3. Edit, then press **Publish**. The live site updates in about 5 minutes (pages are cached).

Every section has **Section settings**: anchor link, background, spacing, width, alignment, animation, hide, and hide on mobile/desktop.

Header menu, header button, footer, phone, email, social links and the mobile call bar are in **Site settings**.

## Make a new page or landing page

- **Page**: for normal site pages that should rank on Google. URL = `/<slug>`.
- **Landing page**: for ads and campaigns. You can hide the menu and footer, add a sticky button, set a campaign name (saved on every lead), an A/B label and an end date. Set **noindex** if the page is only for paid ads.

Start with a **Hero** section — it holds the page's only H1 heading. Add a **Lead form** section so people can enquire. Use **Saved section → Main call to action** to reuse the same CTA everywhere.

## Write a blog post

1. **Blog → Posts → Create**.
2. Add a clear title, summary, cover image (1200×630) with alt text, author and category.
3. Write with Heading 2 and Heading 3 — the table of contents is built from them.
4. Use **Key takeaways**, **FAQ**, **Table** and **Callout** blocks. AI search engines love clear lists, tables and direct answers.
5. Link to at least one **Service** page with an internal link and add it under **Related services**.
6. Fill the **SEO** tab (see below), then publish. Set a future publish date to schedule a post.

## The SEO tab (every page)

The Studio shows a Google preview and a checklist as you type.

- **Focus keyword**: one main phrase per page, e.g. `seo geelong`. Never use the same focus keyword on two pages.
- **SEO title**: 50–60 characters. Keyword first, brand last.
- **Meta description**: 140–160 characters. Who it is for, what they get, a call to action.
- **AI search tab**: write a 40–60 word **quick answer** and 2–5 **key facts** (prices, areas, timeframes). Add **sources** for blog posts. Only write things that are true.
- **Indexing tab**: use **noindex** for thank-you pages, ad-only pages and thin pages.

## Leads

All form enquiries appear in **Leads**, sorted by status. Each lead shows what they sent, the page they came from, the channel (Google Ads, Google search, ChatGPT/AI, social…), the campaign and the ad click ID. Change the **status** as you follow up (New → Contacted → Qualified → Proposal → Won/Lost) and add a deal value.

Leads are private. They are never shown on the website and cannot be read without logging in.

Forms are edited in **Lead forms** (fields, button text, success message, thank-you page, estimated value).

## Redirects

If you change a URL or delete a page, add a **Redirect** from the old path to the new one (301). This keeps your Google rankings.

## Analytics

Add your IDs in **Site settings → Analytics & tracking** (GA4, Tag Manager, Google Ads + lead label, Meta Pixel, Microsoft Clarity, LinkedIn, TikTok). Conversions fire automatically when a form is sent.

## Rules that protect your rankings

- Same business name, phone and suburb everywhere (website, Google Business Profile, directories).
- One page per service and one page per real area you serve — each with unique local content. Copy-paste suburb pages hurt rankings.
- Only real numbers, real reviews and real client results.
- Change **Last meaningful update** only when you really update a page.
